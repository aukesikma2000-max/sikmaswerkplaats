# Sikma's Werkplaats
## Design System v1.0

---

# Ontwerpfilosofie

Sikma's Werkplaats is geen moderne consumentenapp.

Het is een intern werkplaatssysteem dat dagelijks vele uren wordt gebruikt door winkelmedewerkers en reparateurs.

Daarom staat gebruiksgemak altijd boven design.

Het systeem moet:

- Rust uitstralen
- Professioneel ogen
- Snel werken
- Geen afleiding bevatten
- Direct begrijpelijk zijn

---

# Doelgroep

Gebruikers:

- Winkelmedewerkers
- Reparateurs
- Eigenaar

Ervaring met computers varieert van zeer weinig tot gevorderd.

De interface moet daarom ook voor een digibeet direct begrijpelijk zijn.

# Gebruiksvriendelijkheid

Elke veelgebruikte handeling moet binnen twee klikken bereikbaar zijn.

Gebruikers mogen nooit hoeven zoeken.

Belangrijke acties moeten direct zichtbaar zijn.

---

# Responsive

De applicatie is ontworpen voor:

1. Tablet
2. Laptop
3. Desktop

Mobiel is geen prioriteit.

---

# Ontwikkelregels

Bij iedere nieuwe pagina geldt:

- Volg dit design system.
- Gebruik bestaande componenten.
- Houd de interface rustig.
- Voeg geen functies toe zonder overleg.
- Optimaliseer altijd voor snelheid en eenvoud.
