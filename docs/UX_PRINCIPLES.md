# UX Principles

Een winkelmedewerker moet binnen 30 seconden een reparatie kunnen aannemen.

De medewerker hoeft geen technische kennis te hebben.

Een reparateur wil zo min mogelijk klikken.

Belangrijke acties moeten altijd zichtbaar zijn.

Het systeem ondersteunt het werkproces.

Het systeem bepaalt nooit het werkproces.

Twijfel? Kies altijd voor eenvoud.

De medewerker moet het systeem zonder uitleg kunnen gebruiken.

Geen scherm mag "druk" aanvoelen.
